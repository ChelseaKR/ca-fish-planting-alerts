# Trout Truck

Trout stocking schedules, state by state. Trout Truck shows what each state's
wildlife agency publishes about trout stocking, at the agency's own precision
(a week, a day, a report after the fact, or a plan in the agency's words), and
keeps each water's history after the agency's own page moves on. In November
2026 it carries California, Massachusetts, Michigan, New York and Tennessee.
Tennessee's source has not been read successfully since 2026-10-15, so its
pages show that date and nothing newer. The live list is whatever
`snapshot/v2.json` carries; this paragraph is a dated description of it, not
a promise of coverage.

A free website, a free Android app, and an iOS app that is free to browse with
an optional one-time purchase per state. There is no account for any of them.
The website uses Google Analytics 4, which does not load when the browser
sends Global Privacy Control or Do Not Track, or once the visitor presses
"Opt out of analytics" in the site footer, and has its advertising features
turned off. The apps collect nothing and have no analytics
(`docs/DECISIONS.md` 0011). Trout Truck is independent and is not affiliated
with or endorsed by any state agency.

The name is what anglers call the hatchery truck that delivers planted trout
(`docs/DECISIONS.md` 0010). The repository keeps its original name,
`ca-fish-planting-alerts`. The site is live at
<https://chelseakr.github.io/ca-fish-planting-alerts/>.

Status: **Beta.** The website is live and is republished twice a day. iOS
1.0.0, which carries California alone, is with App Review under appeal; the
multistate iOS version is on `main` and has not been submitted. The Android
app is free in each state it carries, with nothing for sale
(`docs/DECISIONS.md` 0044); see `docs/ANDROID-RELEASE.md`.

## Quickstart

```sh
make verify                          # every lint, type, test and security gate
cd ios/PlantingCore && swift test    # the app's data layer
```

Build the whole site offline from a committed CDFW fixture. This writes
nothing inside the checkout:

```sh
cd pipeline && uv sync
uv run cfpa --fixture tests/fixtures/schedule-fresh-2026-09-13.html \
  --fixture-fetched-at 2026-09-13T12:00:00Z --run-today 2026-09-13 \
  --history /tmp/cfpa/history.json --aliases /tmp/cfpa/aliases.json \
  --site-out /tmp/cfpa/site
```

`make verify` needs `uv`, `gitleaks` and `osv-scanner`. See `CONTRIBUTING.md`
for the full gate and `pipeline/README.md` for the pipeline's own commands.

## Shape

- `pipeline/` — Python. Reads each live state's agency source (California's
  is CDFW's weekly planting schedule; the others are in `pipeline/src/*/states/`),
  keeps a per-water history (this is the asset: the agencies' own pages keep
  little or none), and publishes a versioned snapshot as one static file.
  Twice a day; no human step.
- `schema/` — the snapshot contract the app consumes. Owned by the pipeline.
- `site/` — static HTML, generated by the pipeline. One page per water: what
  the agency listed and when, a subscribable `.ics` for California waters, and
  where the apps are. California's pages stay at the site root; other states
  are under `/<xx>/` (`docs/DECISIONS.md` 0025). This is the free discovery
  surface.
- `ios/` — SwiftUI. Favorite waters, background refresh of the snapshot, a
  local notification when a favorite is newly on its agency's schedule or
  report. Free to download, with an optional one-time purchase per state that
  unlocks alerts, the widget and Apple Watch there (DECISIONS 0007, 0009,
  0018, 0025). No server, no push service, no account.
- `android/` — Kotlin and Compose, with the iOS app's features. Alerts and
  the widget are free in each state it carries (DECISIONS 0022, 0044).
- `docs/` — decisions, licenses and attributions.
